Research update · 1 September 2026 · GenomeOcean-4B · eleven targets, three classes

Class-Specific BGC Generation

A class-specific LoRA puts class-appropriate biosynthetic machinery into de novo DNA on three independent compound classes — against controls that produce exactly none. Conditioned on a whole compound class it reaches ~2% of the specificity real clusters have. Conditioned on a single simple subclass it reaches 100%.

Phase 3

One class at a time

The pivot was to stop conditioning on a class label and instead route to a per-class adapter. Phase 1 had measured the class tag at −0.0006 nats — no effect — so the label was never the lever. Target: RIPP, trained on the biosynthetic core only.

Two constraints shaped everything after. We train on the strict core — a median 2,191 nt of a ~21,900 nt region — so generations contain no transport, regulatory or resistance genes by construction. And the 1B's 8,192-token context is a hard model limit, not a config choice.

Correction

What the audit found

Assembling a full report surfaced four defects. Each was caught by measurement, and each is recorded in place rather than edited away.

Retracted — fan-out shard collision Five Phase-4/5 arms at n = 188, WIDE refuted at Holm p = 4.1e-04 and 3.2e-05 Four workers launched with the same --seed wrote byte-identical shards. Effective n was 47–141. Rates survived (duplication was uniform); one of two p-values did not — the 8 kb contrast fell to p = 0.15, n.s. All Phase-3 sets audited clean.
Retracted — extraction truncated on a stop byte Sequences end early; the model has learned to stop The extractor kept only the leading ACGTN run, discarding a median 6.2 kb of 99.9%-valid DNA. It hit adapters ~35× harder than base models, so it loaded onto the treatment arm: 45.5% vs 2.0% below the scoring window.
Corrected — marker-set artifact PKS reaches ≥2 class domains in 74% of real cores vs RIPP's 20% OBLIGATE_DOMAINS[PKS] holds several Pfam models per catalytic domain, so a single T3PKS gene scores 2 unaided. Collapsed to catalytic units it is 0.300; by distinct gene, 0.060 — level with RIPP.
Retracted — the early-stopping speedup ~75% of PKS generation compute runs after the model has finished Measured on the wrong quantity. The median ~1,750 nt stop was the first stop of any kind — overwhelmingly degeneracy, not EOS. With real token ids only 9/24 rows emit EOS at all, so an all-rows exit delivered 1.01×. Batched decoding is bounded by its slowest row. Per-row exit is worth 38.5%; the win from that build was constrained decoding instead.
The finding that replaced the marker artifact is more useful. No class has multi-gene cluster structure in the strict-core span — all three sit at 0.06–0.08. That is a property of strict-core trimming, not of any class, so changing class cannot fix it. Only span width or context can.

Finding

Rarely the harder member

The harder member is, in every case, the longer one — T1PKS at a median 7,665 nt against T3PKS at 1,083. The 1B's training budget is 7,992 nt, so half of all T1PKS records do not fit. The PKS adapter is 59.3% T3PKS by construction, and it reproduced its substrate exactly.

And the limitation survived the model swap. GenomeOcean makes the cyclase at 20/126 = 0.159 against Evo2's 0.062 — higher, but not significantly (p = 0.132), and both sit far under real cores at 0.440. A 6.4× context and 4× the parameters did not lift the harder member. That makes the ceiling look like a property of the substrate — one context limit, one trimming rule — rather than of either model.
Diagnosis

The model was stopping all along

Generations ended early while hit_eos read 0 in every arm ever produced. The cause: token ids 0 (EOS), 1 (PAD) and 32 (space) all decode to the same character, and the whole pipeline read the decoded string.

We never trained token 0. --eos-token appended a five-byte string, |END|, which never once fired. The real EOS came from Evo2's pretraining and our fine-tuning sharpened it 51×. It is now appended unconditionally, with no flag.

This retired a claim that had propagated for a month. The model-comparison doc listed "Evo2 has no usable EOS" as one of three reasons to switch models. Evo2's EOS is real; what GenomeOcean actually offers on this axis is convenience — its tokenizer auto-wraps BOS=1 … EOS=2 and its runtime honours it. The trainable class token remains the genuine structural difference.

Degeneracy is a separate failure. Two mechanisms were tested and both rejected: the pre-collapse context is not worse on-class (p = 0.22), and degenerate records show no more within-alphabet repetition than clean ones. It is an abrupt exit from the nucleotide manifold — encouraging for constrained decoding, since there is no repetition loop to fall into, but whether constraining yields usable sequence there is untested.

Phase 10

Conditioning works. The limit is what you ask for.

Every result above says the model makes only the simplest member of whatever class it is given. The obvious explanation was that "RIPP" is too coarse a thing to ask for — the model is never told which RiPP to build, and antiSMASH's generic RiPP-like rule fires on weaker evidence than any specific one. So we tested that at its limit: one dedicated adapter per subclass, trained on that subclass alone, each measured against its own real-core ceiling.

And azole is the first arm where the novelty gates bite: 25 of its 26 failures are endpoint hits, so its honest rate is 0.133, not 0.158.

The failure mode degrades in three stages, and that is more informative than the rate. At 715 nt the model never misses. Between 1.6 and 2.7 kb its misses are RRE-containing — the RiPP recognition element — or a different genuine subclass: wrong chemistry, but chemistry. Only at 6.3 kb does it collapse to the bare generic rule, 62/63. Competence does not fade smoothly to zero; it passes through a regime where the model still writes real RiPP chemistry and simply writes the wrong one.

The curve is not monotonic, and the middle is unresolved. Lassopeptide sits above redox-cofactor despite being the longer target. Both rest on 12 and 15 detections, their intervals overlap almost entirely, and Fisher gives p = 0.398. The extremes carry the result; the middle fills in the shape and should not be read as an ordering.

What it buys is a selection rule. Sub-kilobase subclasses are solved. Past roughly 3 kb the method produces RiPP-like DNA but not the chemistry it was asked for. That predicts which of the 43 RiPP subclasses are worth a training run before spending one — which is a different kind of result from any single rate on this page.

Phase 11b

It is not that it stops too early

Azole was the only subclass that undershot its target length — 0.54× — and the only one that collapsed to the generic rule. Those co-occurring is suggestive, and the direction is testable: force it past its own stopping point and see whether the chemistry arrives. The reading was fixed before the run. Moves ⇒ the limit is length control, and fixable. Stays ⇒ the limit is compositional, and much deeper.

The limit is compositional capacity, not length control. The model does not fail because it stops writing too early. It fails because it cannot assemble the domain combination the subclass requires — and giving it nearly three times as much sequence does not change that. The collapse is identical at 0.54× and at 1.51× of target length.

The extra 6 kb is not empty — it is filler. The primary endpoint rose (0.133 → 0.175) and so did detection (0.065 → 0.085). So the model fills the space with recognisable biosynthetic material and no subclass chemistry. That is the same shape as an earlier TERPENE result where forcing a minimum length produced longer records with no more biosynthetic genes. Two classes, two mechanisms, one lesson: length buys filler, not structure.
And there is no second stopping point. Suppressing EOS dropped hit_eos from 837/1000 to 112/200 — once pushed past its decision at ~3,390 nt the model does not find a later natural stop, it runs to the cap. Its stopping behaviour is a single decision, not a preference it recovers from.
Two limits on this result, stated rather than buried. The forced arm has 17 detections, so a jump to the ceiling is excluded but a modest improvement is not — settling that needs n = 1000. And min_new_tokens pins a floor, not a target: the model overshot to 1.51×. The strict claim is that length is not the lever anywhere between 0.54× and 1.51×, not that it fails at exactly 1.0×.

Phase 13

The fidelity dial works. It does not buy the chemistry.

The bacteriophage paper generated coherent multi-gene 5.4 kb genomes. It did so under a conditioning signal we never had: a trained token meaning "be 95–100% identical to ΦX174". Its viable designs came back 93.0–98.8% identical to a training sequence. Every arm on this page sits at the opposite extreme, because that dial did not exist in our conditioning. So we built it.

A second token, marking each training record's identity to a frozen reference, inserted after the class token — on the azole adapter's exact training records, with byte-identical hyperparameters and byte-identical decoding. The bucket token is the only thing that differs between this and the Phase-10 azole arm.

The first attempt failed, and the failure is the finding Bucket the records by DNA identity, exactly as the phage paper did 76.5% of azole clusters have zero alignable nucleotide identity to the reference — the top bucket held 3 records against the 30 required. Microviridae is a taxonomic family with a canonical member, so "identity to ΦX174" is a real axis. An "azole-containing RiPP" is a chemical annotation over genomically unrelated clusters. Their conditioning axis does not exist in our data at the level they used it. Re-cut on protein identity, it does — but bimodally: 40 records near-identical, 628 unrelated, 16 in between.

The dial lands, and it lands hard. Detection goes from 0.010 at the low-fidelity end to 0.280 at the high end — a 28-fold swing inside a single adapter. It is not a length artefact: the elevation holds in every length stratum, including sequences under 3 kb (0.175 vs 0.011). And it steers novelty exactly as designed — five records reach protein-level paraphrase at the high end, zero at the low end.

But read that 28× the way Phase 12 taught us to. Almost all of it is the generic RiPP-like call — 36/37 and 54/56 — which is precisely the annotation escape hatch Phase 12 identified. So the dial did not move subclass competence; it moved the catch-all. That makes the flat azole rate more damning, not less: maximum template fidelity bought 28× more of the thing that does not count, and none of the thing that does.

And the chemistry does not move. Pooled across the two well-supported high-fidelity buckets, the azole rate is 3/400 = 0.0075 against Phase 10's 0.002 — p = 0.144. Against its own ceiling, p = 1.4e-58. The model wrote 4.3× as much RiPP-like DNA and zero additional genes: 1.093 against a 3.378 ceiling, unchanged from Phase 10's 1.101. More fidelity buys volume and length, not structure.

Azole's boundary is not a conditioning artefact, and there is no fidelity price at which its chemistry can be bought. We turned the dial the phage paper used, all the way up, and the target chemistry stayed where it was.

Three limits, stated rather than buried. The pooled interval tops out at 0.022 against a ceiling of 1.000 — a jump to the ceiling is excluded, a modest rise to around 2% is not; n = 1000 per bucket would settle it. The no-bucket control is off-distribution, since every training record carried a bucket token, so the load-bearing comparison is high-versus-low bucket within this adapter, which is internally controlled. And DNA novelty never fired once — zero failures, zero warnings, in all six arms — while protein novelty degraded to paraphrase. That is the blind spot the two-gate rule exists for, caught in the act.

Three defences that do not work — checked rather than assumed.

  • "Their target was shorter." It was not — 5,386 nt against our azole's 6,293. Length is not why they win; their target is the smaller one.
  • "They trained on near-duplicates." False. Their set is more diverse at the matched threshold — 94.9% distinct against our azole's 87.7%.
  • "We just need to generate far more." Their funnel is ~36:1, not the ~1000:1 this project had on record. Our 1,000-record azole pool is already about a ninth of their entire per-target sampling budget.

Correction

Three findings that weaken what we can claim

Recorded together because each cuts against the results above, and each was found by checking rather than by being challenged.

Corrected — the multi-gene reference was too low all along Real cores carry n_bio_orfs 1.454; our generations reach 1.03–1.38 1.454 is the class-level 50-core sample. Measured per subclass, real cores carry 1.79–3.38 biosynthetic genes — azole 3.378, T1PKS 2.767. The multi-gene gap is roughly twice what has been reported: 1.10 against 3.378, not against 1.45.
Corrected — the long-target successes are fragments Subclass conditioning reaches its ceiling on targets up to 11.7 kb The genes themselves are short. Across eleven arms the longest generated ORF is a median 0.82× the real one, and for the two large PKS targets it is 0.63–0.65× — a 1,525-aa megasynthase where the real enzyme is 2,332 aa. antiSMASH still calls it T1PKS, because the signature is present.
And antiSMASH is a signature detector, not a cluster validator. It calls genes, runs HMM profiles against the predicted proteins, and fires a rule when the required domains are present within a distance cutoff. A detection means the signature is there — never that the cluster is complete or functional. The defensible claim is "generates a gene carrying the subclass's defining signature", not "generates the subclass." Every rate on this page inherits that limit.

Finding · RIPP

One chemistry out of eleven

The subclass test was the point of the phase. Powered up, it went the other way.

Corrected — small-sample inflation GenomeOcean reaches subclass specificity 1/13 = 0.077 strict, 3/13 = 0.231 lenient At 87 detections it is 2/87 = 0.023 strict and 10/87 = 0.115 lenient — about a third. The gap against the ceiling (0.500 / 0.740) is now decisive, p = 1.7e-11, superseding the earlier "underpowered, uninformative" reading.

The sharper result is richness. Across 87 detections GenomeOcean produced exactly one chemistry — ranthipeptide, twice. Real cores span eleven: azole-containing-RiPP, lanthipeptide classes i/ii/iii/v, lassopeptide, microviridin, thioamitides, triceptide, redox-cofactor, cyclic-lactone-autoinducer. So it is not "produces subclasses rarely" — it is produces one and misses the other ten.

The model-vs-model question is still open, and it is Evo2's n. 2/87 against Evo2's 0/7 is p = 1.0; with seven detections nothing could reach significance. A detection-matched Evo2 arm is generating now.
Method · positives only

The model swap buys frequency, not quality

Reporting changed: the primary is the rate of positives, and every other metric is now read among positives only, because post-generation filtering discards the rest. A negative contributes 0 to the biosynthetic metrics by construction, so the all-records column was re-measuring the hit rate under another name — bio_span_frac reads 0.641 over all records and 0.934 among positives.

Read that way, on TERPENE where it is best powered, GenomeOcean sits at 0.90–1.05 of the real-core value on every structural metric, and Evo2's positives are close behind. The 9.8× model gap is almost entirely a gap in how often a positive appears, not in what one looks like. The single real quality difference: Evo2 calls 2.0× as many genes as a real core, filler from writing 2.5–8 kb where a real core is ~1 kb.

Two caveats, both recorded. frac, co_orient and bio_span_frac saturate among positives (1.20 / 1.10 / 1.07 of ceiling) — above 1.00 there is a symptom of single-gene output, not of quality. And the 2,000 nt window flatters the arm on the primary: widened to 4,000 the ceiling rises 0.440 → 0.680 while GenomeOcean stays flat, so its share of ceiling falls from 29% to 20%.
Closed · bio + transport

The one intervention aimed at multi-gene structure cannot deliver it

bio + transport was the standing candidate for multi-gene content, needing a 185 GB re-stream. Measuring the dataset before building it killed it: across 27,176 RIPP regions the span adds transporters and 3.9× the length but zero biosynthetic genes — in 0.000 of the 15,704 regions that have a transporter.

The reason is structural: the strict span runs from the first biosynthetic gene to the last, so it already contains every biosynthetic gene in the region. Widening to transport pads the ends. It remains legitimate for generating a complete BGC with its exporter — but that is a different goal, and the plan's framing of it was wrong.

X1 · alongside

Generation correctness and speed

One missing capability — seeing the sampled token ids — blocked all of these. vortex returns logits and strings but never ids, and ids 0, 1 and 32 all decode to the same character, so the pipeline could not tell a stop from a collapse. That capability now exists; what remains is wiring it into the generation scripts.

  • X1gToken-id-aware generationBuilt. The sampler is wrapped to mask logits, record ids and exit early — nothing depends on vortex's return value.
  • X1aConstrained decodingWorks, and was the real win from that build: junk ids 247 → 0 at 1.01× cost. Mask every id outside {A,C,G,T,N,EOS} to −∞.
  • X1bTrain the real EOSShipped, and with no flag — id 0 is appended unconditionally. The 5-byte |END| string is retired.
  • X1ehit_eos tests the token idStill open in generate_bgc.py, which reads the retired string and so reports a structural zero. Until it lands, no hit_eos from that path may be quoted as evidence about termination.
  • X1fPer-row early stoppingThe simple version does not work — see the retraction above. Per-row exit is measured at 38.5% of decode compute (157,490 tokens needed vs 256,000 paid) and needs vortex's cached inference_params rebuilt for surviving rows. Cheaper first: shorter requests and smaller batches.
  • X1iSnip-and-replaceDetect a degenerate or zero-length record, discard, regenerate the slot. Rejection sampling; legitimate as selection provided the discard rate is reported.
  • X1dDegeneracy needs its own gateConstraining does not fix it — at a uniform-distribution position masking just forces an arbitrary base.
Phase 13 · next

The next question is data, not parameters

Two candidate explanations for azole were live: the model never learned what an azole cluster is, or it learned fine and its sampling lands elsewhere. Teacher-forcing real held-out clusters through the adapter — the first measurement here that is not a generation metric — settled it against sampling. What is left points at training-set size, which is the one axis where the phage comparison is most lopsided.

  • doneThe fidelity dial, built and sweptTheir identity-bucket conditioning ported onto azole. Detection moves 28× across the dial; the subclass rate does not move at all.
  • doneRedundancy ruled outThe obvious confound — that our long targets are simply more heterogeneous than one viral family — is dead. Across the five RIPP subclasses, effective distinct training examples correlate with the rate at r = +0.007. Azole is the most redundant and the worst performing.
  • doneNot a sampling problemThe azole adapter beats the base model on real held-out azole by only +0.035 bits/nt, better on 28 of 45 records; cyclactone's beats the wrong adapter on 34 of 34.
